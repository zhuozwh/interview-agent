# v0.5.5：RAII 问答检索正确性修复

## 真实触发与归因

用户于 2026-10-01 提问“请用适合口头表达的方式解释 RAII。”，界面最终返回“当前资料库没有找到足够可靠的证据”。本机只读审计显示当时两次请求都路由到 `search_notes`，Tool 耗时分别约 0.1 秒，状态均为 `no_results`、`decision_code=below_score_threshold`，没有调用 LLM。首次运行时同步索引的等待时间不在这段 Agent 追踪中，因此不能据此断言用户感受到的全部等待只有 0.1 秒。

对同一现有索引、同一模型仅做本地只读查询：原问法的 raw Top-5 最高分 `0.561290`，五个候选均不含 RAII，低于 notes 的 `0.58` 阈值。改问“智能指针如何体现 RAII？”时最高分 `0.757728`，并能召回相关笔记。按 `RAII` 精确筛选现有 notes 索引，可找到包含资源管理和析构内容的片段；这证明资料存在，失败发生在问法驱动的召回和阈值门控之间，不是 Router 或 LLM 故障。

## 最小行为变化

- 原向量结果仍按固定 Top-K、排序、`0.58` 阈值和原有事实策略处理。
- 仅 `notes`、仅单个大写技术缩写、仅“解释/什么是/介绍/原理/含义”问题且原结果为空时，增加一次本地已索引正文的精确术语筛选；候选仍用原问题向量排序，最多返回原 Top-K 数量，不扫描 Vault 文件、不下载模型、不发起网络请求。
- 词面降级保留原始相似度；Tool 审计记录 `exact_term_fallback`，成功回答标为 `low`，提醒用户核对引用。常见凭据名不进入该降级。
- 若 notes 问题明确包含至少两个不同的大写技术标识，向量候选必须直接包含其中至少一个，否则 Tool 以 `insufficient_topic_evidence` 停止。该核对仅排除明显主题错位，不能证明整句答案被原文语义支持。
- `no_evidence` 不再附加预设追问，避免在未生成答案时显示“能否结合最小代码示例说明”等不合时宜的建议。
- 单次提问超过 10 秒仍未返回时，界面会说明首次加载模型和更新索引的可能性，并提示无需重复发送；这是等待反馈，不代表检索或生成耗时已缩短。

v0.4.6 及以前的 tag/commit、三个阈值、Top-K、Router、提示词和答案引用校验均未改变。没有配置或调用真实搜索提供方，也没有产生新的远端 LLM 请求或费用。

## 验收与剩余边界

合成数据定向回归覆盖真实 RAII 问法、向量高分但 HTTP3/QUIC 技术标识缺失、相关 QUIC 候选保留、无索引术语以及凭据名停止。定向 Python 测试 **51 passed**。真实现有索引的只读复查对 RAII 原问题返回 `success / exact_term_fallback`，最多五条均含 RAII；最高真实相似度 `0.527788`，不会冒充跨过 `0.58` 的语义命中。

首次在当前 Vault 快照重跑 v0.4.5 的 12-case/19-probe 独立留出集时，一个 notes 硬负例误接受，raw 最高分 `0.585818`。其 `decision_code=evidence_selected` 表明是原向量路径，非新增词面降级；该案例在 2026-08-13 旧快照的最高分为 `0.579579`。问题清单哈希未变，Vault 快照哈希已变化，不能把旧快照的全通过直接当作当前质量结论。加入上述双技术标识主题门禁后，同一当前快照重跑达到 **12-case/19-probe 全通过、0 failure、0 trigger、Vault unchanged**；三域正例、硬负例、跨域和引用完整性均通过。

最终默认离线全回归为 **391 passed、5 skipped**；新增三个通过项分别覆盖真实 RAII 问法的词面降级、双技术标识主题碰撞以及降级成功时的低证据强度。另以现有索引和本地 LLM 替身走通 Agent：`success`、一条当前 `[S]` 引用、`confidence=low`、一次替身调用和 `exact_term_fallback` Tool 追踪。此演示没有请求 `/ask` 或真实远端服务，不证明真实模型输出质量。

2026-10-02 发布前复核：默认离线全回归再次达到 **391 passed、5 skipped**，JavaScript 语法与 Git diff 检查通过；当前 Vault 的同一独立留出集再次达到 **12-case/19-probe 全通过**，`acceptance_passed=true`、`safety_passed=true`、`vault_unchanged=true`。明细仍只保存在 Git 忽略的本地 `acceptance_local/v0.5.5-raii/report.release.json`，不随 tag 发布。

仍需区分“检索到了含同一术语的段落”和“段落足以支持口述答案”。本次未调用真实 LLM，因此不能声称真实模型已经给出合格的 RAII 口述回答。该修复也不解决纯中文同义问法、单术语但无关上下文、源内容事实错误或外部资料合成问题。真实远端验收需要另行确认模型、endpoint、调用数、token、费用与允许外发的 Vault 片段。

这次追踪仅覆盖 Agent/Tool 执行段，不能从约 0.1 秒 Tool 耗时反推出首次提问的总等待时间；运行时确实在首次请求中同步加载模型与增量索引，但尚无该次前置阶段的耗时记录。实际等待时长及性能优化需另行实测。
